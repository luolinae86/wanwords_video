## 角色向再优化建议（评估）

| 优先级 | 建议 | 原因 |
|--------|------|------|
| 高 | 开场 2–3s 手机首页 → 再切练习页（带轻转场） | 先建立「这是万字诀 App」心智，再演示听写 |
| 高 | 解说按画面秒级对齐：说到哪句，屏幕就停在哪句 | 现在解说 24s、画面 34s，后段数字人易空镜 |
| 高 | 练习段保留极轻的产品英文原声（-18~-24dB）+ 键盘声 | 纯解说会丢「听一句」的产品感；键盘声补操作真实感 |
| 中 | 圆形 PiP 加极淡阴影 / 呼吸感边框 | 更像真人摄像头画中画 |
| 中 | 字幕改「左侧圆角气泡」：中文主句 + 英文小字 | 不挡显示器内容，也不压数字人脸 |
| 中 | 裁掉地址栏 / 不出现 wanwords.com | 降限流风险（已有策略） |
| 低 | 片尾 CTA 只出现在字幕区：搜「万字诀」 | 与画面解绑，少广告感 |
| 低 | 同一角色备「说话 / 微笑」两张底，日更换造型 | 降低审美疲劳 |
