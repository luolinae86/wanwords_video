# 真人周播话术草稿（Phase 3 试点）

**频率**：每周 1–2 场，每场 30–45 分钟。  
**人设**：真人主持；可用数字人 15s 片头（`avatar/renders`）。

## 开场（3 min）

1. 自我介绍 + 今晚目标：「带大家现场听一句、打一句」
2. 口播口号：听一句，打一句，练到会用
3. 提醒：评论区扣「试学」发 wanwords.com 链接（或置顶）

## 主体（20–30 min）

1. 打开 wanwords.com 共享屏幕，选一课免费试学
2. 现场完成 5–8 句听写，讲解打错提醒 / 晾衣绳 / 意群答案
3. 若有动画课：演示「观看 ⇄ 练习」
4. 抽 2–3 条评论问题现场答

## 收束（5 min）

1. 总结今晚一句金句
2. CTA：前两课免费试学
3. 预告下场时间 + 本周短视频选题

## 禁止

- 无人挂机、自动回弹幕冒充真人
- 夸大提分承诺
- 展示真实用户隐私头像/姓名
