# 直播合规边界（Phase 3）

## 红线（必须遵守）

1. **禁止无人 AI 互动直播**（抖音明确禁止完全由 AI 驱动互动）。
2. **抖音虚拟人**：形象须在平台注册；背后真人实名；直播时由**真人实时驱动**互动。
3. **视频号**：橱窗/带货场景对「虚拟数字人代播」限制严格；默认用**真人出镜**讲解产品。
4. **小红书**：以短视频矩阵为主；若开播优先真人答疑。
5. AI 生成片头/录播段须按平台要求做 **AI 标识**。
6. 不承诺「24 小时无人挂机躺赚」类话术。

## 允许的形态

| 形态 | 说明 |
|------|------|
| 真人周播 | 现场听写演示 + 答疑，官方直播伴侣推流 |
| 数字人片头 | 开场 10–20s 口播，之后切真人 |
| 录播课循环 | 预渲染讲解段作垫片，**弹幕与转化由真人控** |
| 短视频引流 | avatar/promo 矩阵导流到直播预告 |

## 开播前检查清单

- [ ] 账号实名与经营资质（若带货）
- [ ] 虚拟形象是否已注册（仅当使用虚拟人时）
- [ ] 直播间显著 AI/虚拟标识（若使用）
- [ ] 话术无夸大「包过 / 躺赚」
- [ ] CTA 指向 wanwords.com 试学，不导虚假第三方

## 工具

- 推流：抖音直播伴侣 / 视频号直播 / OBS（真人画面）
- 本仓不提供无人推流、弹幕自动回复或绕过平台检测的脚本
